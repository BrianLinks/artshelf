## Artwork and media

All demo artwork is generated by the program itself (`src/seed/art.ts`, a seeded random number generator drawing shapes
and gradients). No third-party images, fonts, icons or audio are included in the repository.

## Third-party software

This project depends on open-source packages (for example Express, better-sqlite3, bcryptjs, zod, sharp, React and Vite),
each under its own license. Exact versions are pinned in `package-lock.json`. To list their licenses, run:

```
npx license-checker --production --summary
```

Note that `sharp` downloads prebuilt binaries that include the libvips image library, which is licensed under the
LGPL. This repository does not redistribute those binaries; they are installed by `npm install`.

## Demo data

The demo accounts created by `npm run seed` use the fictional domain `demo.artshelf.test` and a published password. They
exist only for local use, and the seed refuses to run when `NODE_ENV=production`. No real personal data is included.
